# #281 E6-01-B3：移除 Swift oracle 与 Golden parity 迁移链路

## 目标

删除已经没有生产消费者、且已被 Electron-owned TypeScript contract tests 接替的
Swift oracle / Golden parity 链路。保留 Swift Core/App 普通测试和仍承担迁移期行为参考
的工具，避免本切片扩大到最终 Swift 源码删除。

## 删除范围

- `Tools/golden-oracle/`、Swift `GoldenContractTests` target 和 `Tests/Golden/`；
- TypeScript Swift-oracle runner、parity comparator、parity-only tests 和 parity Vitest config；
- Swift parity CI job、oracle isolation、E1-02 parity baseline/protocol 文档与脚本；
- 已无 owner 的 manual queue / snapshot-history / manual reconciliation parity fixtures；
- manifest 的 `swiftOwner` 与跨语言 oracle operation，只保留 TypeScript contract registration。

## 保留范围

- Swift `COCHelperCore`、`COCHelperApp`、普通 XCTest、`acceptance-runner`、`smoke-api` 和
  `history-memory-seed`；
- `fixtures/golden/` 中仍被 TypeScript wire/domain/contract tests 使用的 fixture；
- `fixtures/account/` 与 Swift account fixture snapshot 的同步门禁，直到后续 Swift 包删除切片；
- `pnpm test`、fault replay、packaged E2E、Release perf 和发布门禁。

## 验收

- `rg` 不再发现 Swift oracle、GoldenContractTests、Swift parity CI 或旧 Golden 目录消费者；
- `Package.swift` 不再声明 golden-oracle / GoldenContractTests；
- `pnpm test`、`pnpm typecheck`、`pnpm lint`、`pnpm format`、`pnpm test:fault-replay` 通过；
- Swift 普通 `swift test --parallel --num-workers 1` 和 Release App 构建仍通过；
- packaged smoke/E2E 与 Release perf 仍可执行；
- `git diff --check` 通过。
