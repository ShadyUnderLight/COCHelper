# #281 E6-01-C2：删除 Swift package，完成纯 Electron 主线切换

## 目标

删除已经没有生产消费者的 SwiftPM package、SwiftUI 应用、Swift 测试、Swift 资源副本和
迁移期 fixture 同步门禁，使主分支的产品、测试、CI、打包和性能路径全部由 Electron/
TypeScript/Node/Python 离线工具组成。

## 删除范围

- 根 `Package.swift`、`Sources/`、`Tests/`、`Resources/`；
- `scripts/check-account-fixture-sync.mjs` 及其回归测试、root script 和 CI 调用；
- Swift migration-reference CI job；
- 仅用于说明 Swift 迁移期保留物的活动 README、fixtures README 和架构状态说明；
- eslint 中对已删除 Swift 根目录的忽略项。

## 保留范围

- `fixtures/account/`：Electron domain/testkit/perf 测试仍直接消费的匿名 fixture；
- `fixtures/golden/`、`apps/desktop/resources/`、`packages/`、`apps/desktop/`；
- Python catalog/render 工具及历史 `Tools/*/results` 报告；历史报告中的 Swift 命令只作为
  已发生事实，不恢复旧执行入口；
- wire/domain 中用于复刻已冻结数据契约的 `Swift` 命名和历史语义说明，不将其解释为运行时依赖。

## 活动路径收口

- CI 只保留 Electron bootstrap、packaged macOS smoke、Release perf jobs；
- release prepare 只执行 Node/TypeScript 检查与 Electron Forge make；
- `pnpm check:account-fixtures` 删除，fixture 由 Electron 测试自身消费，不再和已删除的
  Swift 快照做同步比较；
- README/架构文档明确当前主线是纯 Electron，Swift 只在历史审计文字中出现。

## 验收

- `git ls-files` 不再包含 `Package.swift`、`Sources/**`、`Tests/**`、Swift app resources；
- 活动 CI、package scripts、release scripts 不再调用 Swift、SwiftPM、XCTest 或 Swift fixture gate；
- `pnpm test`、`pnpm typecheck`、`pnpm lint`、`pnpm format`、`pnpm test:fault-replay` 通过；
- `pnpm package`、packaged smoke/E2E、Release perf provenance/gate 通过；
- Python catalog tests 与 `git diff --check` 通过；
- 全仓活动源码、依赖和产物扫描确认无 Swift runtime/helper/native addon/fallback；
- clean worktree 可独立安装、测试和生成 Electron packaged release。

## 非目标

- 不改变 Electron domain、IPC、renderer、storage、API 或 UI 业务语义；
- 不删除或改写历史性能/验收结果；
- 不把“文档中提到 Swift”误判为运行时依赖，契约出处和迁移审计可保留历史说明。
