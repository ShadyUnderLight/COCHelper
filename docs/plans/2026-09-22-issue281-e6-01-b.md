# #281 E6-01-B1：迁移 Electron/TypeScript fixture 归属

## 目标

切断 Electron、TypeScript domain/testkit、Release perf runner 和离线大城墙生成器对
`Tests/COCHelperCoreTests/Fixtures` Swift XCTest resource 目录的路径依赖，为后续删除
Swift Package、Swift CI 和 golden oracle 建立独立的 fixture 根目录。

## 实施范围

- 新增仓库级 `fixtures/account/`，承载当前匿名账号、官方 API 分页和性能快照 fixture；
- 保持 25 个 JSON fixture 的字节内容不变，并与迁移期 Swift oracle 快照逐文件核对；
- 更新 Electron perf manifest、domain/testkit 测试、History 大城墙校验和生成器读取新根目录；
- 更新 Issue #246 Release 内存验收脚本读取新根目录，并增加新旧快照逐文件一致性门禁；
- 将一致性门禁接入 `pnpm check:account-fixtures` 和 Electron CI；
- 更新当前性能/契约文档，明确 Electron fixture 的归属；
- 保留 `Tests/COCHelperCoreTests/Fixtures/` 的物理快照，直到 Swift oracle 与 XCTest target 在
  后续 E6-01 切片中删除。

## 排除项

- 不删除 Swift `Sources/`、`Tests/`、`Package.swift`、golden oracle 或 acceptance-runner；
- 不迁移 `Tests/Golden/Fixtures`；它仍由当前 Swift oracle parity 测试和 TypeScript golden
  parity 测试共同消费，另行切片处理；
- 不改变 fixture JSON、parser、History、catalog 或 Electron UI 语义；
- 不把诊断性能报告当成数值性能门禁通过。

## 验收

- `fixtures/account/` 包含 25 个 fixture，和 Swift 快照 `diff -qr` 无差异；
- Electron/TypeScript 代码中的生产读取路径不再指向 `Tests/COCHelperCoreTests/Fixtures`；
- `pnpm test`、`pnpm typecheck`、`pnpm lint`、`pnpm format` 通过；
- 相关 Python generator tests 通过；
- `pnpm check:account-fixtures` 通过，且能拒绝缺失文件、额外文件和内容漂移；
- packaged Electron perf runner 能在 clean commit 上从新 fixture 根运行 `overview` 诊断场景；
- `git diff --check` 通过，旧 Swift 快照仍可供迁移期 parity 使用。
