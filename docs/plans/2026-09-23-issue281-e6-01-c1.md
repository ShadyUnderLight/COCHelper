# #281 E6-01-C1：撤掉 Swift 离线工具与旧构建入口

## 目标

在删除 Swift package 之前，先撤掉仍会把维护者引向 Swift 运行链路的离线可执行工具、
旧 Release App 构建脚本和旧 API smoke/验收入口。C1 合并后，活动的验收、打包、性能和
Token 操作路径均由 Electron/TypeScript 工具负责；Swift Core/App、`COCHelper` target、
Debug 隐藏性能样本菜单与普通 XCTest 暂留，仅供 C2 删除 package 前做迁移期参考回归。

## 删除范围

- Swift executable targets：`smoke-api`、`acceptance-runner`、`history-memory-seed`；
- 对应 `Tools/` 源码、`scripts/build_app.sh`、`scripts/configure_coc_api.sh`；
- 旧 Swift acceptance gate、旧 Release memory 脚本和只服务这些入口的活动说明；
- `Tools/perf/generate_large_walls_fixture.py` 保留为离线输入生成器，脱离 acceptance 目录；
- `Package.swift` 中上述三个 executable product/target；CI 中旧 Swift Release App bundle 步骤。

## 保留范围

- Swift `COCHelperCore`、`COCHelperApp`、`COCHelper` target 和普通 XCTest，直到 C2；
- `fixtures/account/` 与 Swift fixture 快照同步门禁，直到 C2 删除 Swift package；
- Electron TokenSettingsPanel/safeStorage、`pnpm package`、packaged smoke/E2E、
  `pnpm perf:release`、`pnpm perf:gate`；
- 已提交的历史 acceptance/perf 报告，不重写其 Swift 时代的事实描述。

## 语义替换

- API token：README 只描述 Electron UI + safeStorage，不再提供 `swift run smoke-api` 或
  `configure_coc_api.sh` 命令；
- Release App：README/CI 只保留 Electron Forge package/make；
- 性能：旧 Swift memory seed/人工 Release 脚本删除；活动性能入口统一为
  `scripts/electron-perf.mjs` 及 `perf:gate`，Swift Debug 隐藏性能样本菜单仍是迁移期参考；
- provenance：Electron perf 不再把 Swift `Sources/` 当作输入根，改为跟踪 Electron
  apps/packages/scripts/fixtures/e2e 输入。

## 验收

- `Package.swift` 不再声明三个 Swift executable；Swift 普通测试仍可运行；
- 活动源码、CI、README 和工具文档不再提供上述 Swift 工具命令；历史报告可保留；
- `pnpm test`、`pnpm typecheck`、`pnpm lint`、`pnpm format`、`pnpm test:fault-replay` 通过；
- `swift test --parallel --num-workers 1` 通过；
- `pnpm package`、packaged smoke/E2E 和 Release perf provenance 仍可运行；
- `git diff --check` 通过，worktree 提交前干净。

## 非目标

- 不在 C1 删除 `Sources/`、`Tests/`、`Package.swift` 或 Swift CI job；这些属于 C2；
- 不迁移历史报告中的旧事实，不删除匿名 Electron fixture；
- 不修改业务 domain、IPC、renderer 或持久化语义。
