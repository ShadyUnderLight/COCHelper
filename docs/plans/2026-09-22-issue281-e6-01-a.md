# #281 E6-01-A：Electron 资源归属脱离 Swift

## 目标

切断 Electron 生产路径对 `Sources/COCHelperCore` 资源目录的硬依赖，为后续删除 Swift 源码、SwiftPM targets 和旧工具链建立可验证的资源边界。

## 本切片范围

- 将生产使用的 `GameCatalog/<version>` 和 `account_name_catalog.json` 迁移到 `apps/desktop/resources/`；
- 更新 Forge `extraResource`、Main catalog service、domain bundled loader 和 release manifest 的路径；
- 更新 catalog 生成/校验/渲染工具及其测试的 bundled resource 路径；
- 保持 catalog schema、版本、asset protocol、DTO 和业务行为不变。

迁移期间 Swift oracle 仍由现有 CI 构建，因此 `Sources/COCHelperCore/GameCatalog`
与 `Sources/COCHelperCore/Resources/account_name_catalog.json` 只保留指向
`apps/desktop/resources/` 的符号链接；它们不是 Electron 生产 fallback，也不再保存
第二份资源。E6-01-B 删除 Swift Package/CI/oracle 时一并删除这两个链接。

## 排除项

- 不删除 `Package.swift`、Swift `Sources/`、Swift `Tests/` 或迁移期 oracle；
- 不迁移 `Tests/COCHelperCoreTests/Fixtures` 和 `Tools/acceptance-runner`；它们属于后续 E6-01-B/C；
- 不改变 catalog 内容、manifest schema、资源协议或 renderer 行为；
- 不引入旧路径 fallback。旧 Swift 资源路径不再保存资源副本，仅作为迁移期 oracle 的
  构建链接；本切片合并后它不是 Electron 生产或离线工具入口。

## 验收

- `rg` 不再发现生产/工具代码读取 `Sources/COCHelperCore/GameCatalog` 或 `Sources/COCHelperCore/Resources/account_name_catalog.json`；
- domain bundled loader、Main catalog service 和 Forge make 使用新资源根；
- 迁移期 `swift build --target COCHelperCore` 与 Swift bundled catalog tests 仍能通过，
  且只读取 Electron 资源根的单一副本；
- catalog/domain 相关测试、全量 Vitest、typecheck、lint、format 通过；
- packaged smoke/E2E 能加载 catalog 及图标资源；
- `release:prepare` 的 manifest catalog provenance 与迁移前一致；
- `git diff --check` 通过，worktree 干净后再提交。
