# #281 E6-01-B2：迁移 TypeScript golden fixture 归属

## 目标

切断 Electron/TypeScript domain、wire、testkit 和 parity harness 对 Swift `Tests/Golden`
目录的路径依赖，为后续移除 Swift oracle 和 GoldenContractTests 建立 Electron-owned golden
fixture 根目录。

## 实施范围

- 新增 `fixtures/golden/manifest.json` 与 15 个 golden JSON fixture；
- 将 manifest 中的 fixture 路径改为 `fixtures/golden/...`；
- 更新 TypeScript testkit、wire/domain contract tests 和 parity tests 读取新根目录；
- 新增 `pnpm check:golden-fixtures`，逐文件比较 Electron golden fixture 与迁移期 Swift
  快照，并接入 Electron CI；
- 更新 Electron 契约文档，区分当前 TS fixture 根目录和迁移期 Swift oracle 快照；
- 保留 `Tests/Golden/` 物理快照，供当前 Swift oracle/XCTest 使用。

## 排除项

- 不删除 `Package.swift`、Swift `Sources/`、Swift `Tests/`、golden-oracle 或 Swift CI；
- 不改变 golden JSON 内容、manifest case ID、协议版本、parity 语义或业务代码；
- 不在本切片迁移 Swift `GoldenContractTests`；其删除归属后续 E6-01-B3；
- 不把 Swift oracle 接入 Electron 生产运行路径。

## 验收

- `fixtures/golden/` 包含 15 个 JSON fixture，和 `Tests/Golden/Fixtures/` 逐文件一致；
- TypeScript 源码不再读取 `Tests/Golden/`；
- `pnpm check:golden-fixtures` 通过，且同步门禁拒绝缺失、额外文件和内容漂移；
- `pnpm test`、`pnpm test:parity`、`pnpm typecheck`、`pnpm lint`、`pnpm format` 通过；
- Swift parity/XCTest 仍能读取旧快照并通过，证明迁移没有改变协议内容；
- `git diff --check` 通过。
